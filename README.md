# Cardllector

Registro personal de colecciones de cartas coleccionables (de momento, Magic: The Gathering), con
el precio de mercado de Cardmarket y la evolución del valor.

- Qué piezas hay, cómo arrancarlo en local y cómo desplegarlo: [`docs/architecture.md`](docs/architecture.md)
- Modelo de datos y reglas de negocio: [`docs/data-model.md`](docs/data-model.md)

Los datos de las cartas y los precios vienen de [Scryfall](https://scryfall.com). Cardllector no
está producido ni avalado por Wizards of the Coast ni por Scryfall.
