# Tapmat

Registro personal de colecciones de cartas coleccionables (Magic: The Gathering, Pokémon y álbumes
de fútbol), con el precio de mercado de Cardmarket, la evolución del valor, mazos de Commander y un
escáner con la cámara. Hasta el 2026-09-14 se llamaba Cardllector.

- Qué piezas hay, cómo arrancarlo en local y cómo desplegarlo: [`docs/architecture.md`](docs/architecture.md)
- Modelo de datos y reglas de negocio: [`docs/data-model.md`](docs/data-model.md)

Los datos de las cartas y los precios vienen de [Scryfall](https://scryfall.com). Tapmat no
está producido ni avalado por Wizards of the Coast ni por Scryfall.
